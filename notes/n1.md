#### MySQL8.0.45版本的下载问题

大一的时候，装了mysql9.2版本沿用至今，但考虑到项目兼容性，所以决定使用8.x版本。

8.x版本的下载先后遇到了不少问题：

1. 原mysql9.2版本下载残留
2. 官方留下8.x版本是直装下载，缺少配置

接着就是解决和学习：

1. 删除尤其是编程软件，应从控制面板，文件夹，注册表，windows服务多个维度才能彻底删除
2. 需要在mysql下载目录下创建my.ini配置文件，写好配置，再注册到服务中，mysql才能生效
3. win+R，输入services.msc可打开服务窗口，配置mysql自启动
4. 写好环境变量后，以 mysql -u root -p 登录mysql

前后大概花了3h有效时间，但最后成功了依旧很开心。



#### Docker容器部署Redis

redis没有合适的windows版本，所以使用docker部署，下载dockerdesktop，拉取redis7.2镜像，然后启动容器。

映射到6379端口，选定持久化文件，这里desktop配置很方便，可直接在图形化界面查看。

终端查看：

1. docker ps 查看所有容器状态
2. docker exec -it [redis-name] redis-cli，进入redis（如有密码需输入）
3. 出现127.0.0.1:6379>，即为连接成功

docker容器部署很简单，redis也可选择在docker终端配置，不过持久化和命令行会麻烦点。



#### Knife4j——Swagger接口增强工具

能够自动检测所写接口，并发送测试数据，开发时很方便

使用也很简单：

  1.添加依赖

```
<dependency>
    <groupId>com.github.xiaoymin</groupId>
    <artifactId>knife4j-openapi3-jakarta-spring-boot-starter</artifactId>
    <version>4.4.0</version>
</dependency>
```

  2.编写配置

```
# springdoc-openapi 配置

springdoc:
  group-configs:
    - group: 'default'
      paths-to-match: '/**'
      packages-to-scan: com.jun.template.controller # 此处指定controller包位置

# knife4j 接口文档配置

knife4j:
  enable: true
  setting:
    language: zh_cn
```

  3.访问接口

创建对应接口后，访问http://localhost:8123/api/doc.html即可，此处需替换为自己的端口路径

#### Mybatis-Flex框架

#### 登录状态获取流程

登录：前端发送信息，后端验证信息，并将登录状态写入服务器request。

获取登录：前端请求，后端从服务器request读取信息，返回给前端。



#### 关于异常处理

项目大量使用异常处理，诸如实现类：

```
@Override
public boolean userLogout(HttpServletRequest request) {
    // 先判断是否已登录
    Object userObj = request.getSession().getAttribute(USER_LOGIN_STATE);
    if (userObj == null) {
        throw new BusinessException(ErrorCode.OPERATION_ERROR, "未登录");
    }
    // 移除登录态
    request.getSession().removeAttribute(USER_LOGIN_STATE);
    return true;
}
```

当方法发生业务异常时，该方法停止，请求停止，返回报错，服务器继续运行。

一般异常Exception分为runtime和business，一个是运行时异常（代码跑到这才会发生异常，如null），一个是业务异常（自定义），二者本质差不多，发生时只会导致该线程停止，不会让jvm服务器停止。所以常用在方法中，检测业务逻辑并终止方法。

通过编写全局异常处理类（AOP），可以使上述异常发生时被捕捉，可以返回前端友好报错信息。
