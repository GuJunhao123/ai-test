#### 项目部署

##### docker容器部署

基本步骤：

1. 分别在后端和前端目录下新建Dockerfile，分构建和运行两个阶段构建Dockerfile，减少镜像体积

2. 前端配置nginx.conf，代理后端和WebSocket请求

   后端修改application-prod.xml改为生产环境配置

3. docker build -t name .  分别构建前后端，并启用容器

可归结为，编写Dockerfile文件，修改相关配置，docker构建并启动。

补充：

- 前端静态资源由nginx托管，前端代码由浏览器运行
- 后端迁移到容器时，需更改mysql，redis，rabbitmq对应端口配置

进阶：

- docker部署的第三步可以替换为docker-start.sh，docker-stop.sh脚本，一键启动停止
- 多容器同时构建，编写 docker-compose.yml 配置多容器，执行 docker compose up -d  一键启动项目所需所有容器



##### 云服务器部署上线

传统部署方式过于麻烦，故直接采用docker容器一键部署。

项目正式上线，需购买云服务器获取公网ip（使得用户可以访问），购买域名（正规且易于搜索），申请https证书（安全保障）。





#### 拓展：多模块输入输出支持

流程：

1. 引入模型多模块功能标签（准备阶段），数据库对应表新增图片和联网字段，更新模型同步方法
2. 腾讯云存储（第三方工具），获取私钥并创建桶，编写配置类，封装TencentCosUtil工具便于调用
3. 上传图片接口（核心1），创建FileService调用TencentCosUtil，并使用UploadController获取图片，返回url
4. AI对话加入url，联网功能（核心2），扩展对话请求参数，加入图片url，联网字段，并判断是否多模块输入，以及联网
5. 创建图片生成的对话接口（额外），另写一套controller，service，并直接使用restTemlate调OpenRouter相应接口（因为SpringAI暂不支持图片生成）



- 在前端上传图片成功后，将返回的url自动填入AI对话请求参数中
- 图片输入功能通过构建用户消息时添加media字段实现，联网功能只需在模型名后面加 :online 即可自动联网
- 收到图片数据后直接上传COS，后端和数据库使用url传递，需要前端显示时再使用CDN拉取，提升性能
- AI联网搜索的结果存储在metadata字段中，解析结果并写入回复的消息的toolsUsed字段
